Alur Kerja Cepat Kader KPM / HDW (5 Sasaran Resmi):

  1. Pilih Tab Sasaran: Gunakan 5 tab resmi (Keluarga Sasaran, Anak 0-59 Bulan, Remaja Putri, Calon Pengantin, Ibu Hamil & Nifas) untuk merekap data hasil kunjungan lapangan.
  2. Login Portal Kemendesa: Klik tombol kuning "Login Portal e-HDW Kemendesa" di pojok kanan atas untuk membuka ehdw.kemendesa.go.id/app-pendataan/ di tab baru.
  3. Salin Data Baris e-HDW: Klik tombol Salin Data e-HDW pada baris sasaran untuk menyalin NIK, identitas, dan status indikator layanan, lalu tempel ke formulir portal Kemendesa.
  4. Ekspor Excel Multi-Sheet: Klik Ekspor Excel Multi-Sheet (.xlsx) untuk mengunduh file Excel dengan 5 lembar kerja (sheet) terpisah sesuai kategori e-HDW.
