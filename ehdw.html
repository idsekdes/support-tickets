Alur Kerja Cepat Kader KPM / HDW:

  1. Input & Verifikasi Offline/Lokal: Gunakan Lembar Kerja Syam Digital ini untuk merekap seluruh data sasaran (Bumil, Baduta, Balita, Catin) di lapangan. Data tersimpan otomatis di perangkat Anda.
  2. Buka Portal Resmi Kemendesa: Klik tombol kuning "Login Portal e-HDW Kemendesa" di pojok kanan atas untuk membuka halaman ehdw.kemendesa.go.id/app-pendataan/ di tab baru.
  3. Gunakan Fitur Salin Cepat: Klik tombol Salin e-HDW pada baris sasaran untuk menyalin NIK & ringkasan layanan, lalu tempel (Paste) langsung ke formulir web e-HDW Kemendesa.
  4. Arsip Laporan Desa: Gunakan tombol Ekspor Excel (.xlsx) atau Cetak / PDF sebagai lampiran laporan rembuk stunting dan pertanggungjawaban KPM Desa.
