Integrasi Permanen Google Sheets (Code.gs)

Salin kode di bawah ke Google Sheets → Extensions → Apps Script, lalu Deploy sebagai Web App

Langkah Singkat Deploy Web App:

1. Buka Google Sheets baru → klik menu Extensions → Apps Script.

2. Hapus kode bawaan, tempel kode di bawah ini, lalu klik Save.

3. Klik Deploy → New deployment → pilih type Web app → set Execute as: Me & Who has access: Anyone → klik Deploy.

4. Salin Web app URL (https://script.google.com/macros/s/.../exec) dan tempel ke kolom URL di menu Pengaturan.
